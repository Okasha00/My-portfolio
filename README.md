# Okasha Sameer — Next.js Portfolio

Frontend-only portfolio built with Next.js, React, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Notes

- Portfolio content is based only on the supplied CV.
- No backend or database is required.
- Replace/add a public resume file later if desired.
